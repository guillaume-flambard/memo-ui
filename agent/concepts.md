# Concepts

## Core concepts that memo-ui recombines

### Precision + Warmth
The central tension that makes the system unique. Engineering precision (types, tokens, structure) meeting human warmth (motion, personality, surprises).

### System + Soul
Not just a component library — a design system with personality. The "geist" layer on top of technical foundation.

### Rare accent
Inspired by Alan Chester: the ocre color is scarce on purpose. It appears only when it matters — as punctuation, not decoration.

### Cinematic motion
GSAP-driven reveals and transitions (700ms, cinematic easing) for major state changes. Not nervous, not overwhelming.

### Micro-interactions
Motion-driven hover states and feedback (150ms) for immediate response. Linear-style timing.

### Technical honesty
Design systems for solo practitioners. No over-engineering, no enterprise patterns. What works, ships.

### Agent-ready
Jon Neylon style: voice layer, positioning, audience, messaging encoded so AI agents can produce on-brand output.

### Mono-first
Geist Mono as the voice of the system — kickers, badges, metadata. Technical, precise, signature.

### Dark mode native
CSS variables with `[data-theme="dark"]` selector. Zero JS runtime cost for theming.

### RSC-ready
Zero `'use client'` directives where possible. Components work in React Server Components.

## Anti-concepts

### Generic SaaS UI
What memo-ui is NOT: default Bootstrap, Material Design, or generic shadcn clones.

### Over-designed
Motion for motion's sake. Gradients where a solid color works. Shadows where a border is cleaner.

### Enterprise patterns
A/B testing variants, endless configuration, "flexible" everything. Opinionated beats flexible.

### Template-driven
Copy-paste components without understanding. Every component should feel considered, not generic.
