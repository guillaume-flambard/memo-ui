# Differentiation

## What I do differently

### 1. Design systems for solo practitioners
Most design systems target teams with processes, reviews, and handoffs. I build for one person — agile, iterative, honest. No enterprise patterns, no over-engineering.

### 2. Agent-ready brand encoding
Jon Neylon style: voice layer, positioning, audience, messaging encoded as markdown/YAML. Drop into Claude Code, Cursor, or Codex and get on-brand output automatically.

### 3. Rare accent philosophy
Alan Chester style: one accent color (ocre) used sparingly as punctuation, not decoration. The data, the pivot, the δ. Scarce on purpose.

### 4. Technical + design literacy
I speak both languages fluently. Typography, spacing, motion from design perspective. Types, patterns, performance from engineering perspective. No translation layer needed.

### 5. Motion as storytelling
Not just "it moves" — motion conveys meaning. GSAP cinematic reveals for major transitions (700ms). Motion micro-interactions for feedback (150ms). Linear-style timing throughout.

### 6. Zero runtime theming
CSS variables with dark mode via `[data-theme="dark"]`. No JS config files, no ThemeProvider. The browser resolves colors natively.

### 7. Mono-first voice
Geist Mono as the system's voice — kickers, badges, metadata. Technical, precise, signature. Not an afterthought.

### 8. largo-ai heritage
Typography and colors inspired by my most refined project. Space Grotesk/Geist/Geist Mono. Paper and ink base. Proven in production.

## What I refuse

### Over-engineering
- A/B testing variants
- Endless configuration options
- "Flexible" everything
- Enterprise patterns for solo projects

### Generic aesthetics
- Default Bootstrap/Material Design
- Generic shadcn clones
- Templates without personality
- "Safe" design choices

### Design for design's sake
- Motion without meaning
- Gradients where solid works
- Shadows where borders are cleaner
- Complexity without purpose

### Tool worship
- Using tools because they're popular
- Following trends without thought
- Framework-first, problem-second
- Copying without understanding
