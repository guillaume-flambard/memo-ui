# Messaging

## Taglines

- "Design systems that feel human"
- "Precision with personality"
- "Systems that breathe"
- "Engineering meets emotion"

## Key phrases

- "I build design systems with soul"
- "Your brand, encoded in code"
- "Ship faster with a design system that's actually you"
- "Stop copying. Start expressing."

## Value propositions

- **For indie devs**: Ship premium UI without the design debt
- **For solo founders**: A design system that scales with you
- **For AI-native devs**: Agent-ready brand encoding
- **For design engineers**: Systems that respect both craft and code

## Voice patterns

- Direct and concise
- Technically grounded but accessible
- Confident but not arrogant
- Human-first, tool-second

## Anti-patterns

- Don't use jargon without explanation
- Don't overpromise or exaggerate
- Don't sound like a generic SaaS
- Don't sacrifice clarity for cleverness
