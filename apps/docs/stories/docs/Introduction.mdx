# memo-ui

Personal design system: **paper + ink**, with **ocre** used as scarce punctuation. Typography pairs **Space Grotesk** (display) and **Geist** (body).

## Positioning

*"The engineer who gets design"* — system rigor without sterile UI. Precision meeting warmth.

## What lives here

| Area | Contents |
| --- | --- |
| **Components** | Button, Input, Text, Icon, Badge, Divider, Card, Checkbox, Radio, Modal, Tabs, Select, Tooltip, Toast, Label, Textarea, Switch, Spinner, Avatar, FormField, Link, Breadcrumb, Pagination, Skeleton, Progress, Alert |
| **Layout** | Stack, Grid |
| **Docs** | This foundation set (tokens, a11y, agents/MCP) |
| **Next** | Theme presets, brand assets, denser navigation patterns |

## How to use this Storybook

1. Open a component under **Components** or **Layout**.
2. Use **Controls** to tweak props; **Accessibility** on the **Canvas** tab for axe.
3. **Interactions** shows `play` function results (PASS / FAIL).
4. Autodocs (Docs tab) mirrors props from TypeScript + JSDoc.

## Packages

```tsx
import { Button, Card, Stack } from '@memo-ui/react';
```

Tokens and Tailwind theme: `@memo-ui/core` (`packages/core`).
